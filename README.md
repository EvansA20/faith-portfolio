# Faith Ayooluwa Gbadero — Artist Portfolio MVP

A responsive, editorial-style portfolio website built with HTML, CSS and vanilla JavaScript.

## Media folders

The portfolio uses the supplied local artwork and studio images from `assets/images/`. The Studio and Media sections are image-only; no video files are required.

## Contact flow

The `Contact Faith` button and contact form use `mailto:` to open the visitor's configured email client. Messages are addressed to `gbaderofaitha@gmail.com` with a pre-filled subject and editable body. The visitor reviews and sends the message from their own email account; no password, API key, SMTP service, or message storage is used.

## Deploy

Upload the folder to GitHub and import it into Vercel, or deploy the static folder with any static hosting provider.
